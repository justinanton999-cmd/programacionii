# Semana 02 – Calculadora de Edad

## Nombre de la actividad
Calculadora de Edad Aproximada en Java (Semana 02: Variables y Operadores)

## Descripción del programa
Programa de consola desarrollado en Java que solicita información básica
al usuario y calcula su edad aproximada en años y meses, además de indicar
si es mayor de edad. Se aplican variables, tipos de datos, entrada por
Scanner y operadores aritméticos y comparativos.

## Datos solicitados
- Nombre completo del estudiante
- Carné
- Año de nacimiento
- Año actual

## Cálculos realizados
- **Edad aproximada** = Año actual − Año de nacimiento
- **Edad aproximada en meses** = Edad aproximada × 12
- **¿Es mayor de edad?** = Edad aproximada >= 18 (variable boolean)

> Nota: la edad es aproximada porque el cálculo utiliza únicamente
> el año de nacimiento y el año actual, sin considerar el mes ni el día.

## Instrucciones para ejecutar el proyecto
1. Abrir el proyecto `semana-02-variables-operadores` en IntelliJ IDEA.
2. Verificar que la clase `CalculadoraEdad` esté dentro de la carpeta `src`.
3. Ejecutar el método `main` con el botón ▶ Run.
4. Ingresar los datos solicitados por la consola:
   nombre, carné, año de nacimiento y año actual.
5. Ver el resultado en la consola.
