# Sistema de Cálculo de Envíos

## Descripción
Aplicación de consola en Java que calcula el costo de envíos nacionales e internacionales aplicando Programación Orientada a Objetos.

## Objetivo
Desarrollar una aplicación que calcule costos de envíos usando clases, herencia, polimorfismo, sobrecarga y encapsulamiento.

## Temas aplicados
- Clases y objetos
- Encapsulamiento (atributos privados con getters/setters)
- Herencia (EnvioNacional e EnvioInternacional heredan de Envio)
- Sobrescritura de métodos (calcularCostoFinal)
- Sobrecarga de métodos (mostrarResumen)
- Polimorfismo (variable Envio apunta a subclases)
- Validación de entrada de datos
